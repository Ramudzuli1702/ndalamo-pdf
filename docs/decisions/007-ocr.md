# 007. OCR with Tess4J 5.19, fast English and Afrikaans models
Date: 2026-11-04
## Context
OCR PDF makes scans searchable (SPEC §4). Tess4J wraps Tesseract, which is native Windows code. It needs language model files ("tessdata"), and those files decide both accuracy and installer size. The newest Tess4J (5.20.0, Tesseract 5.5.3) crashed as soon as it started ("Invalid memory access" in `TessBaseAPIInit1`). Its DLL needs the Microsoft Visual C++ runtime 14.40 or newer. The JDK 22 we use ships its own copy, version 14.36, and the JVM loads that copy before the newer one Windows has in System32. Tess4J 5.16 to 5.19 (Tesseract 5.5.1 and 5.5.2) all work with it.
## Decision
- Use Tess4J **5.19.0**, pinned in `pom.xml`. The project's own PDFBox 3.0.8 dependency still wins over the 3.0.7 that Tess4J asks for.
- Bundle the **tessdata_fast** models for English (`eng`, 4.1 MB) and Afrikaans (`afr`, 2.7 MB), Apache 2.0, licence in `src/main/resources/tessdata/tessdata-LICENSE.txt`. Fast models are a quarter the size of tessdata_best and read clean scans just as well.
- Tesseract can't read from inside the jar, so the models are copied once to `%LOCALAPPDATA%\Ndalamo\tessdata` (`OcrEngine.dataFolder`). They are copied again only if the size changes.
- Pages are drawn at 300 dpi in grey, and each word goes on the page as invisible text (rendering mode "neither"), stretched to the word's width. The page looks exactly the same.
- If Tesseract can't start at all, the run stops with a plain message about the Visual C++ runtime (`ToolProblem`) instead of failing every file with a stack trace.
## Consequences
- The app grows by about 7 MB of models (plus Tesseract's DLLs inside Tess4J).
- Other South African languages (e.g. Tshivenda, isiZulu) have no official Tesseract models yet. Adding a language later means dropping its `.traineddata` file into `tessdata/` and adding it to the language choice.
- Packaging (chunk 20): the bundled runtime should carry a VC++ runtime of 14.40 or newer. Then Tess4J can be upgraded past 5.19. Until then, don't upgrade it without running `OcrToolTest`.
