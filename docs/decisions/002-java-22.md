# 002. Use Java 22 and JavaFX 22
Date: 2026-11-04
## Context
The spec originally named Java 21 (LTS). The development machine has JDK 22.0.2 as its default JDK, with Maven already running on it.
## Decision
Build and run Ndalamo on Java 22 with JavaFX 22. Compile with `maven.compiler.release` 22.
## Consequences
- Java 22 is not a long-term-support release and receives no further updates; 22.0.2 is the final build.
- `jpackage` bundles the runtime of the JDK that runs it, so the installer ships Java 22.
- Moving to a newer JDK later (e.g. the next LTS) should be a version bump in the parent `pom.xml` plus a new decision record.
