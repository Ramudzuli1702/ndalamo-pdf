Installing LibreOffice

NdalamoPDF uses LibreOffice to turn Word, Excel and PowerPoint files into PDFs. LibreOffice is free, and everything still happens on your PC — your files are never uploaded.

You only need LibreOffice for Office to PDF. Every other NdalamoPDF tool works without it.

Steps

  1. On a PC with internet, go to libreoffice.org and choose Download. Pick the Windows (64-bit) version. If this PC is offline, download it on another PC and copy the file over with a USB stick.
  2. Open the downloaded file (it ends in .msi) and follow the installer. The usual choices are fine.
  3. When it has finished, go back to NdalamoPDF and click I’ve installed it — check again.

If NdalamoPDF still can’t find it

Click Locate it and choose soffice.exe. It’s in the program folder inside the folder LibreOffice was installed in, usually:

C:\Program Files\LibreOffice\program\soffice.exe

NdalamoPDF remembers where it is, so you only do this once.
